# כלים להכנת התבניות

התבניות ב-`templates/` הן קבצי ה-Word המקוריים, שבהם כל מקום למילוי הוחלף בתגית בצורה
`{{שם-שדה|הטקסט המקורי}}`. האתר מחליף כל תגית בערך שהוקלד. אם השדה נשאר ריק, חוזר הטקסט המקורי
(`<השלם מידע>` או קו ריק).

- `tag.py` - מתייג טפסים רשמיים של מינהל התכנון (עם `<השלם מידע>`), לפי התווית שלפני כל שדה.
  `python3 tag.py מקור.docx יעד.docx`
- `tag_local.py` - מתייג טפסים עם קווים ריקים (`____`), לפי רשימת שדות לכל טופס (`MAPS`).
- `blanks.py` - מציג את הקווים הריקים בטופס עם מספר לכל אחד, כדי לכתוב את הרשימה ב-`MAPS`.
- `build_forms.py` - בונה את `forms.js` (רשימת הטפסים והשדות של כל אחד). מריצים מתיקיית `omer`.

קבצי `.doc` ישנים צריך להמיר קודם ל-`.docx` (למשל: `soffice --headless --convert-to docx קובץ.doc`).
